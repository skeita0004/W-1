# Westan One

## 概要

卒業制作展に出展するゲーム  
西部開拓時代をテーマとした、複数のミニゲーム集  

## 諸元

### プラットフォーム  

x64  
Windows11

### 開発環境

Visual Studio 2026  
MSVC++

## ブランチ

### master

説明省略

### Engine

エンジン部分に変更を加える際に使用するブランチ  
各ミニゲームにエンジン部分の変更を適用する場合は、このブランチをマージすること  
また、エンジン部分の変更が主なブランチも、ここにマージすること

### feature/glTFLoader  

エンジンに、glTFファイルの読み込み・表示機能を追加するためのブランチです。

### feature/Network

エンジンに、ネットワーク通信機能を追加するためのブランチです。

### \d{2}_.+

各々のミニゲームを制作するブランチです。
必ず二桁の数字のあとに、アンダースコアをつけて、その後に1文字以上のミニゲーム名をつけてください。
2桁の数字は、すでに存在するミニゲームブランチの中で、先頭の数字が最も大きいものに、1を加算したものにして、
重複や番号飛ばしがないようにしてください。
例：99_HitAndBlow
